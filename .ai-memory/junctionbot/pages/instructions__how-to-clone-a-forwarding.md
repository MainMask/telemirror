1. Open the chat with Junction Bot and tap **Menu** (**Меню**).
2. Select a forwarding.
3. In the forwarding settings, next to **From** (**Откуда**) and **To** (**Куда**) there are **gear icons**. By clicking them you can create a **clone (copy)** of the current forwarding, **keeping all settings**, while changing the source or the destination.

### Clone to a new source
4. Let's create a clone of the current forwarding with a changed **source**. To do this, tap the **To** (**Куда**) gear [sic — see open questions] and select **Clone to another source** (**Клонировать на другой источник**).
5. Select the **new source**.
6. Done. A clone of the forwarding with the **new source** has been created.

### Clone to a new destination
7. Now let's try cloning the forwarding by creating a **new destination** for it.
8. Select the **new destination**.
9. Done. A clone of the forwarding with the **new destination** has been created.
