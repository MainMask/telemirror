# .ai-memory: persistent working memory for AI agents

This folder is the shared memory of AI agents working on this repo. **Start with [`HANDOFF.md`](HANDOFF.md).** It says what is in progress, where it stopped and what to do next.

| Path | Contents |
|---|---|
| `HANDOFF.md` | Current state of the Junction-parity task and how to resume it |
| `TASK.md` | The owner's original task spec, verbatim |
| `decisions.md` | The owner's answers to open questions |
| `current-project/overview.md` | Map of this repo (telemirror) |
| `junctionbot/` | Knowledge base about the reference product; see its `README.md` |
| `gap-analysis.md` | Feature-by-feature comparison with the reference, plus UX and architecture gaps and open questions |
| `tools/` | Crawl helpers (`html2md.py`, `mark.py`) |

Rules: everything in this folder is written in English. Chat with the owner is in Russian.
